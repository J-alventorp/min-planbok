# Min Plånbok

Ett roligt, färgglatt budgetverktyg på svenska. Håll koll på fasta utgifter,
egna kategorier och vad som är kvar att spendera — med uppmuntrande
meddelanden på vägen, inte en tråkig kalkylark-känsla.

Allt sparas lokalt i webbläsaren (localStorage) — inget konto, ingen backend.

## Funktioner

- Flera oberoende budgetar via flikar, var och en med egen valuta och periodtyp (månad/vecka)
- Fasta utgifter och egna kategorier med live spent/kvar-spårning
- Historikbaserade budgetförslag när en ny period börjar
- Uppmuntrande meddelanden vid viktiga trösklar (50/80/100 %) — aldrig skambeläggande

## Utveckling
